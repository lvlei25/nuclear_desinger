# TC-09 配置外置

> 对应变更记录：`spec/changes/2026-10-17-P1工程质量-配置外置-版本号-CI.md`
> 测试脚本：`testcases/test_tc09_config.py`（6 条用例）
> 核心目标：验证评分权重与阈值已外置到 `config/settings.py` 的 `ScoringConfig`，且默认值与历史硬编码完全一致（行为回归保护）

## 用例清单

| 编号 | 用例 | 验证点 |
|------|------|--------|
| TC09-001 | 默认配置字段值回归 | `ScoringConfig.default()` 全部 29 个字段值 = 历史硬编码值 |
| TC09-002 | 设计器默认持有默认配置 | `NucleicAcidDesigner()` 默认构造与显式传默认配置计算结果一致 |
| TC09-003 | 自定义 HF1 GC 区间生效 | 宽区间 [0,100] 必过 / 窄区间必不过，标准文案跟随配置 |
| TC09-004 | 自定义脱靶阈值生效 | `check_off_target` 结果 threshold 字段反映当前配置 |
| TC09-005 | 自定义推荐分级阈值生效 | 抬高下限降级、归零升级为"推荐" |
| TC09-006 | 实例间配置隔离 | 不同实例各自配置互不影响，默认值不受污染 |

## 设计要点

- **回归保护**：TC09-001 将每个字段的期望值显式写死，防止后续无意改动默认值破坏历史行为兼容
- **正反验证**：自定义配置用"放宽必过 + 收紧必不过"双向验证参数真实生效，而非仅检查字段读取
- 默认值修改属于科学性变更，须走 spec/changes 记录并同步更新 TC09-001 期望值
