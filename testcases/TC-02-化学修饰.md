# TC-02 化学修饰模块用例（src/chemical_modification.py）

公共前置：`ChemicalModifier` 实例化后 modifications 为空；递送测试使用 `DeliverySystem` 静态方法。

| 编号 | 用例标题 | 输入 | 预期结果 |
|------|---------|------|---------|
| TC02-001 | 添加修饰 | add_modification(2, '2OMe') | 列表 1 项，position=2，type='2OMe'，含修饰说明信息 |
| TC02-002 | 未知修饰类型 | add_modification(1, 'XYZ') | 抛出 ValueError |
| TC02-003 | 移除与清空修饰 | 添加 2 项后 remove(1)、clear() | remove 后剩 1 项；clear 后 0 项 |
| TC02-004 | 标记格式输出 | pos=2 加 2OMe，apply("ATCG") | "ATmCG"（tests/ 中预期 "A[2OMe]TCG" 为断言错误） |
| TC02-005 | 合成订单格式输出 | pos=2 加 2OMe，apply("ATCG", 'synth') | "AmTCG" |
| TC02-006 | 越界位置不生效 | pos=10，序列仅 4nt | 原序列 "ATCG" 不变 |
| TC02-007 | siRNA 推荐策略 | suggest_modifications('siRNA') | 4 项，类型含 2OMe 与 PS |
| TC02-008 | ASO/miRNA 推荐策略 | suggest_modifications('ASO'/'miRNA') | 均非空列表 |
| TC02-009 | GalNAc 修饰方案 | S1 与其反义链 | platform='GalNAc'，duplex='21+21'，sense 输出以 "-GalNAc" 结尾，AS 输出以 "p" 开头（5' 磷酸化），validation.valid=True |
| TC02-010 | LNP 修饰方案 | 同上，platform='LNP' | SS 仅奇数位 sugar='2OMe'，偶数位 None；sense 输出以 "-dTdT" 结尾 |
| TC02-011 | 种子区糖修饰覆盖 | GalNAc 方案 AS 链 pos2-8 | sugar 全部非 None（Step 7 兜底生效） |
| TC02-012 | 切割位点排除 FANA | GalNAc 方案 AS 链中心区（索引 8-11） | 该区间无 sugar='FANA' |
| TC02-013 | 递送方式推荐 | '肝脏' / 未知组织 | ['GalNAc','LNP'] / ['LNP'] |
| TC02-014 | 剂量计算 | (21,'肝脏') / (40,'眼睛') | 1.05 / 1.0（碱基剂量*长度系数，系数上限 2.0） |
