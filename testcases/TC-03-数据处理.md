# TC-03 数据处理模块用例（src/data_processing.py）

公共前置：所有文件读写均在 pytest 之外的系统临时目录（tempfile.TemporaryDirectory）中进行，用例结束自动清理。

| 编号 | 用例标题 | 输入 | 预期结果 |
|------|---------|------|---------|
| TC03-001 | FASTA 写读回环 | 2 条序列（含 130nt 长序列） | 读回内容一致；长序列按每行 60nt 换行落盘 |
| TC03-002 | FASTA 空序列头忽略 | 文件含一个有序无列的头 | 读回字典不含该头 |
| TC03-003 | CSV 写读回环 | 含中文字段的 2 行数据 | 读回字段与值完全一致（UTF-8） |
| TC03-004 | CSV 空数据写入 | write_csv([], path) | 不生成文件，方法静默返回 |
| TC03-005 | JSON 写读回环 | 嵌套 dict + 中文 | 读回数据与原对象相等，中文不转义落盘 |
| TC03-006 | 目标基因加载别名 | load_target_genes(csv) | 等价于 read_csv，返回字典列表 |
| TC03-007 | 设计结果保存别名 | save_design_results(csv) | 落盘内容可被 read_csv 读回 |
| TC03-008 | 序列库增查列删 | SequenceDatabase（临时目录） | 添加后 get 返回含 name/sequence/length 的 dict；list 含该名；删除后 get 返回 None、delete 返回 False；查询不存在名称返回 None |
