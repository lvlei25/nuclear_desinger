# 功能变更：log 日志系统（运行状态可人工查看）

- 日期：2026-10-15
- 状态：done
- 类型：新增功能
- 涉及模块：src/logger.py（新增）、gui.py、demo.py、src/ncbi_blast.py、log/（新增目录）

## 变更内容

落实待办池 P1"logging 替代 print"的基础版本，使程序运行状态可通过日志文件人工查看：

1. 新增 `src/logger.py`：`setup_logging()` 统一配置，日志按天写入 `log/app_YYYYMMDD.log`（UTF-8 编码，避免 Windows GBK 乱码），同时保留控制台输出；`get_logger()` 按模块取子 logger；重复调用幂等（不重复挂 handler）
2. 入口接线：gui.py、demo.py 启动时调用 setup_logging；gui.py 注册全局异常钩子，未捕获异常写入日志（无人值守可事后排查）
3. 错误路径接入：gui.py 约 20 处诊断 print 与 ncbi_blast.py 4 处错误 print 改为 logger.error/warning（控制台显示行为不变，同时落盘）；ncbi_blast 提交成功记录 INFO（含 RID）
4. demo.py 的演示 print 保持不变（属于演示输出，非运行日志）
5. log/ 目录加入版本库（.gitkeep 占位），*.log 运行文件已被 .gitignore 排除

## 影响范围

- 不改变任何计算与业务逻辑；控制台可见输出保持一致（错误信息文本不变）
