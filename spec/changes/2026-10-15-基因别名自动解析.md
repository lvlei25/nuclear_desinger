# 功能变更：基因别名自动解析（NCBI 检索增强）

- 日期：2026-10-15
- 状态：done
- 类型：功能修改
- 涉及模块：gui.py（PubMedQuerier 类）、testcases/（TC-05、TC-06）

## 背景与根因

GUI 按"基因编号 + 种属"检索 mRNA 时，用户输入别名（如 ALK-7）报"未找到"。探针实测确认根因：NCBI Nucleotide 库的 `[Gene Name]` 索引只认官方符号（ACVR1C 命中 16 条，ALK-7 为 0 条），而 Gene 库可用别名解析（ALK-7 命中 1 条）。网络本身无问题。

## 变更内容

1. `PubMedQuerier` 新增 `resolve_official_symbol(gene_name, organism)`：先 ESearch Gene 库取 GeneID，再 ESummary 取官方符号（如 ALK-7 → ACVR1C）；解析失败返回 None
2. `search_nucleotide_mrna` 保留原有直接检索逻辑在前；当检索无命中时调用别名解析，命中官方符号则用官方符号重试一次检索，后续 efetch 流程不变
3. 解析过程写日志（INFO 记录别名映射，WARNING 记录解析失败），GUI 未命中对话框逻辑保持不变
4. 解析与重试失败均回退为返回空列表，不改变现有异常行为

## 影响范围

- 仅影响"直接检索无命中"的分支：官方符号检索行为与现状完全一致
- 新增用例：TC-05 增 2 条 Mock 用例（解析单元 + 回退流程）、TC-06 增 1 条真实在线用例（ALK-7 → ACVR1C，离线自动跳过），总数 88 → 91

## 验证方式

- TC05-008/009（Mock）与 TC-06 在线组 6/6 通过（含新增 TC06-006 真实别名解析，79.5s 完成真实 NCBI 往返）
- 真实链路验证：search_nucleotide_mrna("ALK-7") 实测返回 ACVR1C 的 2 条 mRNA 转录本
- 用户 GUI 实测日志（21:57）："基因别名解析: ALK-7 -> ACVR1C，使用官方符号重试检索"、"官方符号 ACVR1C 检索到 1 条序列"
- 用例总数 91 → 92（后续缺陷防护 +1 见 debug 记录）
