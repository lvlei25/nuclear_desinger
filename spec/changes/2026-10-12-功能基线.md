## 当前功能基线（截至 2026-10-12）

### 序列设计（src/sequence_design.py）
- 类 NucleicAcidDesigner：互补链/反向互补链、GC 含量、序列校验、ΔG 与 5' 端稳定性、siRNA 设计、免疫刺激性检测、脱靶检测（check_off_target）、硬过滤（hard_filter）、Reynolds 评分、Amarzguioui 评分、Uitei 检验、热力学不对称性、种子区复杂度、靶区域加成、siRNA 综合评估（comprehensive_sirna_evaluation）、候选序列批量查找（find_sirna_candidates）、序列质量检查、特异性评分、ASO 设计、序列优化、shRNA 生成
- 类 SequenceAnalyzer：基序查找、Tm 计算、回文序列检测

### 化学修饰（src/chemical_modification.py）
- 类 ChemicalModifier：修饰的添加/删除/查询/清空、修饰标记输出（apply_modifications）、修饰策略推荐（suggest_modifications）、siRNA 修饰设计（design_siRNA_modification，支持 GalNAc 平台）
- 类 DeliverySystem：递送方式推荐（recommend_delivery）、剂量计算（calculate_dosage）

### 数据处理（src/data_processing.py）
- 类 DataHandler：FASTA/CSV/JSON 读写、靶基因加载、设计结果保存
- 类 SequenceDatabase：序列库的添加/查询/列表

### 同源性分析（src/ncbi_blast.py）
- 基于 NCBI BLAST API 的远程检索：异步提交、结果轮询、XML 解析、脱靶位点评估

### 图形界面（gui.py，tkinter）
- 序列设计、化学修饰、递送系统、序列数据库等标签页
- 综合评估展示：结构/药效/稳定性/特异性/质量多维表格

### 其他
- demo.py：命令行演示
- tests/：test_sequence_design.py、test_chemical_modification.py
