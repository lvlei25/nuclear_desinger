# 问题调试：GUI 引用未定义属性 gene_name_var

- 日期：2026-10-15
- 状态：resolved
- 涉及模块：gui.py

## 现象

用户运行 GUI（Python gui.py），基因输入 ALK-7 完成 mRNA 获取与 siRNA 评价后，日志出现：

```
2026-10-15 21:57:32 [ERROR] __main__: siRNA规则评价失败: 'NucleicAcidDesignGUI' object has no attribute 'gene_name_var'
```

后续的 NCBI BLAST 同源性分析展示被中断。

## 定位

- 全文件检索 `gene_name_var`：仅 2660、2755 两处引用，无任何定义点（其他 Tk 变量均有 `self.xxx_var = tk.StringVar(...)` 创建语句）
- 设计页基因输入控件实际为 `self.gene_id_entry`（ttk.Entry，无 StringVar），既有代码取值惯例为 `self.gene_id_entry.get().strip()`（975、1043 行）
- 结论：2660/2755 两处应为 `gene_id_entry`，属于既有编码笔误。此前异常被"siRNA规则评价失败"的 print 吞掉不可见，接入 logging 后才显形（日志系统首次实战定位缺陷）

## 修复方案

两处引用改为 `self.gene_id_entry.get().strip()`，取值语义与设计页输入一致；其余逻辑不动。

## 修复后验证

- 2660/2755 已改为 `self.gene_id_entry.get().strip()`，py_compile 通过
- 新增防回归用例 TC05-010（源码静态审计：无 gene_name_var 引用），TC-05 全组 10/10 通过
- 留待用户 GUI 实测：重新设计后 siRNA 规则评价应能继续执行 NCBI BLAST 同源性分析展示
